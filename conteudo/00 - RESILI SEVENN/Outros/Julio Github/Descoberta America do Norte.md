## Candidatas destacadas para deep-dive (Phase 2)

Selecao criterizada por: (a) pricing publico, (b) cases visiveis, (c) diferencial claro vs. concorrencia, (d) relevancia direta para Raya ou V3 Nexus.

### B2B white-label (para benchmark V3 Nexus)

1. **DashClicks** — pricing publico em 3 tiers ($87 / $267 / $537), dashboard branded, hub completo de services. Benchmark direto para estrutura de pacotes + plataforma self-serve.
2. **Vendasta** — canadense, entry muito baixo ($95/mo), marketplace + plataforma. Referencia para modelo hibrido "plataforma + fulfillment".
3. **E2M Solutions** — flat-rate ($1,500/mo ~15–20h), 400+ agencias parceiras. Benchmark para posicionamento "previsibilidade financeira para a agencia parceira".
4. **InvisiblePPC** — pricing publico tier ($595 -> $495, 10% acima de $5k spend). Excelente referencia para PPC vertical especifico.
5. **Conduit Digital** — 100% USA team, premium partner-only, 20+ canais. Benchmark de posicionamento "premium white-label USA-based".

### B2C full-service (para benchmark Raya Studio)

6. **WebFX** — retainers a partir de $650/mo + plataforma proprietaria (MarketingCloudFX). Benchmark para "SMB-friendly com stack tecnologico proprio".
7. **Hawke Media** — "Outsourced CMO" framing LA, DTC/SMB premium. Benchmark de posicionamento de marca/brand narrative.
8. **Single Grain** — min $10K, thought-leadership (Eric Siu + podcast). Benchmark de content/autoridade como canal de aquisicao.
9. **GrowthSpree** — flat-fee $3K/mo, transparencia radical ("sem %-of-spend"). Benchmark de anti-agency positioning.
10. **Major Tom** — cross-border Canada + NYC, mid-to-enterprise. Benchmark para modelo multi-mercado (util se Raya pensar expansao US a partir do Brasil).

## Padroes observados (para informar estrategia Raya/V3 Nexus)

- **B2B white-label USA raramente publica pricing completo** — DashClicks, Vendasta, Agency Platform e Clickx sao excecoes notaveis. A maioria (Conduit, That! Company, 51Blocks, OneIMS, Rocket Driver) mantem "on request" — o que cria espaco para V3 Nexus publicar pricing como diferencial.
- **Range de custo white-label bem definido:** SEO basico $300–$1,500/mo wholesale; PPC flat $500–$2,500/mo ou 10–15% do spend; dev retainers a partir de $1,500/mo (~15–20h). Markup tipico para a agencia-revendedora: 40–60% de margem.
- **B2C SMB USA:** entry realista entre **$1,500 e $3,500/mo** para servico focado; **$3,000–$10,000/mo** para full-service; $10K+ vira mid-market. Cidades premium (NYC, SF, LA) puxam para $3K–$7K entry.
- **Canada:** pricing um pouco abaixo dos EUA para o mesmo nivel de servico; $2K–$10K/mo Toronto/Vancouver para SMB.
- **Setup fees acima de $5K sao "red flag" no mercado** (GrowthSpree destaca isso publicamente) — Raya/V3 Nexus pode se diferenciar com onboarding leve.
- **Vertical courses/infopreneurs e SaaS SMB** tem agencias-niche com posicionamento claro (Think Orion, Funnels of Course, GrowthSpree, SaaSHero) — nao ha dominante absoluto, espaco para players boutique.
- **AI-first white-label esta emergindo em 2026** (Rocket Driver lancou AI Agents platform em jan/2026) — angulo quente para V3 Nexus nao ficar atras.
